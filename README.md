# 🦴 KneeMRI & 3D Posterior Tibial Slope (PTS) PACS Workstation

Quantitative assessment tool for Posterior Tibial Slope (PTS) and ACL strain risk using proton-density weighted knee MRI volumes.

Created by: **Rianna-Maria Tanase**

---

### 📚 Dataset Attribution & Citation
This application utilizes sample records from the **KneeMRI Dataset** licensed under [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).

**Citation:**
> Štajduhar, I., Mamula, M., Miletić, D., Ünal, G. *Semi-automated detection of anterior cruciate ligament injury from MRI*, Computer Methods and Programs in Biomedicine, Volume 140, 2017, Pages 151–164. https://doi.org/10.1016/j.cmpb.2016.12.006

**Data Source:** Clinical Hospital Centre Rijeka, Croatia.
